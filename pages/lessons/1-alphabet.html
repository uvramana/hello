Lesson 1: Telugu Alphabet (Aksharamala)

Learn the complete Telugu writing system consisting of vowels (అచ్చులు) and consonants (హల్లులు). This fundamental lesson is essential for reading and writing Telugu.

Introduction to Telugu Script

The Telugu script is an ancient writing system with a rich history. Unlike English, Telugu is written with complete syllables rather than individual letters. Each consonant carries an inherent "a" sound (అ), and vowels modify this sound.

Key Facts:

  • 60 basic characters in the Telugu alphabet
  • 16 vowels (అచ్చులు)
  • 36 consonants (హల్లులు)
  • Written from left to right
  • Primarily used in Andhra Pradesh, Telangana, and by Telugu speakers worldwide

హల్లులు - Basic Consonants (Velar & Palatal)

Consonants in Telugu can be grouped by the part of the mouth used to pronounce them. Here are the first groups:

Velar Consonants (Ka-varga)

Character Name Sound with 'a' English Equivalent
క Ka క + అ = కా "k" (like in "cat")
ఖ Kha ఖ + అ = ఖా "kh" (like in "khan")
గ Ga గ + అ = గా "g" (like in "go")
ఘ Gha ఘ + అ = ఘా "gh" (like in "aghast")
ఙ Nga ఙ + అ = ఙా "ng" (like in "ring")

Palatal Consonants (Cha-varga)

Character Name Sound with 'a' English Equivalent
చ Cha చ + అ = చా "ch" (like in "church")
ఛ Cha (aspirated) ఛ + అ = ఛా "chh" (emphatic ch)
జ Ja జ + అ = జా "j" (like in "judge")
ఝ Jha ఝ + అ = ఝా "jh" (emphatic j)
ఞ Nya ఞ + అ = ఞా "ny" (like in "canyon")

Important Notes on Consonants

  • Inherent Vowel: Each consonant naturally has an "a" sound. For example, క = ka (ka), not just "k"
  • Using Different Vowels: To change the vowel sound, you add vowel marks. For example:
    • క + ా = కా (kā)
    • క + ి = కి (ki)
    • క + ు = కు (ku)
  • Consonant Clusters: When consonants come together, they form complex characters called "conjuncts"

✏️ Practice Exercises

Exercise 1: Vowel Recognition

Write down all 16 vowels from memory. Practice writing them 5 times each to develop muscle memory for the script.

Exercise 2: Consonant Familiarization

Practice writing consonants from the Velar and Palatal groups. Focus on proper stroke direction and shape.

Exercise 3: Reading Practice

Read the consonant-vowel combinations (consonant + vowel) out loud. Example: కా (kā), కి (ki), కు (ku)

Exercise 4: Pronunciation

Spend 5 minutes daily pronouncing each character. Try to distinguish between similar-sounding characters (like క vs ఖ).
